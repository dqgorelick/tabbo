# Project

Tabbo is a tab-management browser extension with hotkeys for Chrome and Firefox.

- Features: move tabs left/right, pop tabs out, send tabs between windows with custom UI.
- Screenshots via `captureVisibleTab` require explicit opt-in on settings page.
- Details: see `README.md`.
